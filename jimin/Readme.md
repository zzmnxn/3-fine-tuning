### 결과 분석 요약
- **정확도:** LoRA Fine-Tuning(80.95%)의 성능은 일반 Fine-Tuning(85.15%)과 **더 낮습니다.**
- **학습 효율성 (시간):** LoRA 학습 시간이 일반 학습 시간보다 **1.2 배** 빠릅니다. (시간 절약)
- **자원 사용량 (메모리):** LoRA는 GPU 메모리를 **1.6 배** 적게 사용합니다. (GPU 메모리 절약)
   **모델 저장 용량:** 일반 Fine-Tuning은 전체 모델 가중치 **110,623,495**개를 학습하는 반면, LoRA는 **1,480,711**개만 학습합니다. 이는 **75 배** 이상 적은 수치로, 저장 및 배포에 매우 효율적입니다.
